# Contributing

lumemor is in the **design-complete, pre-development** stage. Once development starts, this file will cover the dev setup, code style, and workflows.

A few things that are already settled:

- **No CLA** — contributions are accepted under AGPL-3.0; you keep your copyright on your contribution
- Keep pull requests small and focused; open an issue first for anything larger than a bug fix
- All repository content (code, comments, commits, docs, issues) is in **English**
- Translations live in [`i18n/`](i18n) as flat JSON — see the i18n README (contribution guide coming)
- Design decisions are tracked in the design docs; if a change contradicts a settled decision, say so in the issue

Thank you for helping build lumemor 💛
