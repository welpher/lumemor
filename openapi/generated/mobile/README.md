# lumemor_api (EXPERIMENTAL)
The single source of truth for the lumemor instance API. One contract
generates the Go server stubs, the TypeScript web client types and the
Flutter Dart client; hand-written bindings must not drift from it.

Conventions shared by every endpoint:

- All paths are served under the `/api/v1` prefix. Breaking changes bump
  the prefix to `/api/v2`; `v1` stays compatible across at least two
  major releases.
- Errors use a stable envelope with a machine-readable `code`; `message`
  is an English technical description for debugging and is never
  localized. Client UIs translate `code` through their i18n tables
  (translation key = the lowercase error code).
- Web clients authenticate with the `lumemor_session` cookie issued
  by `POST /auth/login`; mobile clients hold the bearer token issued
  by `POST /auth/pairing/consume` and send it as
  `Authorization: Bearer`. Both credentials front the same session
  records.
- System timestamps (`createdAt`, ...) are RFC 3339 UTC (`Z`).
- IDs are UUIDv7.
