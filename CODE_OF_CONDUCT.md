# Code of Conduct

## Our standards

Be kind and constructive. We are building a family photo library — the community should feel like one too.

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints and experiences
- Gracefully accepting constructive criticism
- Focusing on what is best for the community

Examples of unacceptable behavior:

- Harassment, personal attacks, or discriminatory language of any kind
- Publishing others' private information without permission
- Trolling, insult comments, or other conduct considered inappropriate in a professional setting

## Enforcement

Instances of abusive behavior may be reported to the repository maintainers (privately, via GitHub or the contact in [SECURITY.md](SECURITY.md)). Maintainers may remove, edit, or reject contributions that violate this code of conduct.

This code of conduct is adapted from common open-source community standards.
